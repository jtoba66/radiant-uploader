# Radiant Uploader

> [!WARNING]  
> This project is outdated. Please don't try to use it as-is.

The Radiant Uploader is a tool to make uploading permanent files to Jackal easy and fun.

The `needs-updated` branch contains the latest radiant commit. If you want to update Radiant, the first step is updating Jackal.js and then fixing all the changes to the JJS API since v4.
